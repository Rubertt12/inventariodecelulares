        Como Usar a Plataforma

        Siga estes passos para gerenciar seu inventário de celulares de forma eficiente.

        1. Vincular a Pasta de Dados

        Antes de tudo, clique no botão Vincular Pasta no menu lateral. Escolha uma pasta no seu computador onde todos os dados (banco de dados, fotos, etc.) serão salvos. Esta ação só precisa ser feita uma vez, o sistema lembrará da pasta nas próximas vezes.

        2. Cadastrar um Novo Aparelho

        1. Vá para a aba "Monitor & Cadastro".
        2. Ligue a câmera e clique em Capturar Foto para registrar a imagem da etiqueta do aparelho.
        3. Com a imagem capturada, use o atalho + Shift + T para ativar a ferramenta de captura de texto (OCR) e selecione a área com os dados.
        4. Clique no botão Colar OCR para que o sistema preencha os campos de IMEI e S/N automaticamente.
        5. Confirme os dados e clique em Salvar Entrada no Estoque para finalizar.

        3. Editar um Item

        Na tela de Estoque Disponível, clique no botão de editar () na linha do item desejado. Os campos de Modelo, Localidade e Data se tornarão editáveis. Após ajustar, clique em Salvar.

        4. Vincular um Termo de Saída

        1. Vá para a aba "Vincular Termo / Saída".
        2. Preencha os dados do colaborador (Ticket, Nome, Matrícula, etc.).
        3. No campo "Aparelho Disponível", comece a digitar o modelo ou S/N para encontrar o dispositivo no estoque e selecione-o.
        4. Preencha o número do Chip (se houver) e clique em Vincular e Salvar. O aparelho sairá do estoque de disponíveis e o termo será adicionado ao histórico.

        5. Registrar uma Devolução

        Quando um aparelho entregue é devolvido, encontre-o na lista de Estoque Disponível. O status será "Entregue". Clique no status para abrir os detalhes da entrega e, em seguida, clique em Registrar Devolução deste Aparelho. O item será movido para o Estoque de Usados.

        6. Edição em Lote

        1. Na tela de Estoque Disponível, marque as caixas de seleção dos itens que deseja editar.
        2. Um painel de ações em lote aparecerá no topo. Use os seletores para escolher o novo Modelo ou Localidade.
        3. Clique em Aplicar Edição para salvar as alterações em todos os itens selecionados.

        7. Gerar Termos em Lote

        Na aba "Gerador de Termo", você pode carregar uma planilha (CSV/Excel) com os dados de vários colaboradores e aparelhos para gerar todos os PDFs de uma só vez em um arquivo ZIP.
